Plants vs. Zombies Hybrid v0.25 — English macOS Release

QUICK START
1. Move “Plants vs. Zombies Hybrid v0.25 English.app” to Applications.
2. Open the app.

The dedicated macOS installer is recommended. It installs the app in Applications
and checks Rosetta 2 on Apple silicon.

REQUIREMENTS
- macOS 13 or later
- About 1.5 GB of free disk space
- Rosetta 2 on Apple silicon

Windows, CrossOver, and a separate .NET installation are not required. The game
includes its Godot and .NET runtimes. English saves and logs are kept separately
from the Chinese release.

GATEKEEPER
This community build is ad-hoc signed and is not Apple-notarized. If macOS blocks
the first launch, Control-click the app, choose Open, then confirm Open.
