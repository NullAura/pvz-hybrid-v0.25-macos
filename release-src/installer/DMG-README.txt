植物大战僵尸杂交版 v0.25 — macOS 安装包

安装：
1. 双击“安装植物大战僵尸杂交版v0.25.pkg”。
2. 按照 macOS“安装器”中的步骤完成安装。
3. 从“启动台”或“应用程序”文件夹启动游戏。

无需 Windows 或 CrossOver。

Apple 芯片 Mac 若缺少 Rosetta 2，安装器会通过 Apple“软件更新”服务
自动安装该官方兼容组件。首次安装请保持网络连接。

当前安装器如未使用 Developer ID 签名，首次打开可能需要在 Finder 中
右键安装包并选择“打开”。正式公开分发版本应使用 Developer ID 签名并
通过 Apple 公证。
