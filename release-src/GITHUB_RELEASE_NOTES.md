## 植物大战僵尸杂交版 v0.25 — macOS Release

适用于 macOS 13 及更高版本。

- Intel Mac 可直接运行。
- Apple 芯片 Mac 需要 Rosetta 2。
- 不需要 Windows 或 CrossOver。
- 包含 Godot 4.7 Stable Mono 与 .NET 9 x64 自包含运行时。
- 已修复 `/coin 100000`、图形指令面板和 `/debug openalllevel on`。
- 进入关卡后可使用 `/win` 按正常结算流程记录通关。

首次启动请右键 `.app`，选择“打开”。本包没有 Apple Developer ID 公证，因此 macOS 会要求手动确认。

本次 Release 已从最终 ZIP 解压并验证签名、执行权限与冷启动，成功加载 37 张地图。
