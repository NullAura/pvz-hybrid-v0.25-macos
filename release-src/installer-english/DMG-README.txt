Plants vs. Zombies Hybrid v0.25 — English macOS Installer

INSTALL
1. Double-click “Install Plants vs. Zombies Hybrid v0.25 English.pkg”.
2. Follow the steps in the macOS Installer app.
3. Open the game from Launchpad or the Applications folder.

Windows, CrossOver, and a separate .NET installation are not required.

On Apple silicon, the installer checks for Rosetta 2. If Rosetta is missing, the
installer uses Apple's Software Update service to install the official component.
Keep an internet connection available during the first installation.

This community build is not signed with an Apple Developer ID and is not notarized.
If macOS blocks the installer, Control-click the package in Finder, choose Open,
and confirm that you want to open it.
